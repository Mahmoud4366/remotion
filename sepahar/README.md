## 🌟 سپهر چیست؟

سپهر یک **پنل فرماندهی Cloudflare** است که به‌جای ساختن بک‌اند، دیتابیس و ربات واسط، **مستقیم از داخل مرورگر شما** به API رسمی کلودفلر وصل می‌شود. کلید (API Token) شما هرگز از مرورجت خارج نمی‌شود و فقط در حافظه‌ی محلیِ خودتان ذخیره می‌گردد.

```
  مرورگر شما  ──────(کلید + HTTPS)──────►  api.cloudflare.com
        ▲
        └── نتیجه‌ها مستقیم در همین صفحه رندر می‌شوند
```

## ⚡️ چرا سپهر بهتر است؟

| | پنل‌های کلاسیک (مثل زئوس) | سپهر |
|---|---|---|
| نصب | ربات تلگرام / سایت دیپلوی + صبر | **فقط باز کردن یک فایل HTML** |
| بک‌اند | Worker + D1 + ساب‌دامین | **صفر** — همه‌چیز در مرورگر |
| داده‌ها | از دیتابیس واسط (تاخیر و محدودیت) | **مستقیم از API رسمی کلودفلر** |
| کلید شما | دست سرویس واسط | **فقط در مرورگر خودتان** |
| سرعت بارگذاری | چند صفحه، چند درخواست زنجیره‌ای | **یک فایل، رندر زیر یک ثانیه** |
| هزینه | مصرف روزانه Worker | **مصرف API ناچیز و کنترل‌شده (فاصله قابل تنظیم)** |

## ✨ امکانات

- 📦 **ترافیک دقیق**: حجم امروز / ۳۰ روز (GB / MB / TB) با نمودار ۳۰ روزه و مقایسه با دیروز
- 📱 **تعداد ورودی‌ها**: شناسایی دستگاه‌ها (آی‌پی‌های منحصربه‌فرد) به‌همراه آی‌پی‌های پرتحرک
- 🌍 **جغرافیا**: کشورهای برتر با پرچم، حجم و درخواست
- 🛡️ **مرکز حملات**: رویدادهای WAF، فایروال، Rate-Limit و DDoS در ۲۴ ساعت اخیر با نمودار ساعتی
- ⚔️ **واکنش یک‌کلیکه**: مسدودسازی / رفع مسدودی آی‌پی حمله‌گر + حالت «زیر آتش» (Active Challenges)
- 📡 **چنددامنه‌ای**: شناسایی خودکار همه‌ی دامنه‌های حساب + جابه‌جایی آنی بین آن‌ها
- ⏱️ **حالت زنده (LIVE)**: به‌روزرسانی خودکار با شمارش معکوس و وقفه‌ی قابل تنظیم (۳۰ تا ۳۰۰ ثانیه)
- 🧠 **حالت نمایشی**: بدون کلید هم رابط کامل با داده‌های نمونه قابل مشاهده است
- 📲 **کاملاً واکنش‌گرا**: دسکتاپ، تبلت و موبایل

## 🚀 شروع سریع (۲ دقیقه)

1. **گام ۱** — فایل `get-key.html` را باز کن و با دکمه‌ی **کلید جادویی** کلیدت را بساز.
2. **گام ۲** — فایل `index.html` را باز کن، کلید را بچسبان و بزن **ورود به پنل**.

> 💡 حتی بدون باز کردن دست‌خورد: روی GitHub روی `index.html` کلیک کن و دکمه‌ی **Open with GitHub Pages** (یا Preview) را بزن — پنل همان‌جا اجرا می‌شود.

## 🌍 انتشار آنلاین (لینک اینترنتی)

### روش ۱ — GitHub Pages (رایگان، پیشنهادی)
1. در ریپازیتوری، وارد **Settings → Pages** شو
2. Source: **Deploy from a branch** · Branch: `main` · Folder: `/sepahar`
3. بعد از ۱–۲ دقیقه: `https://<USERNAME>.github.io/<REPO>/sepahar/`

### روش ۲ — Cloudflare Pages (سریع‌ترین)
1. در داشبورد: **Workers & Pages → Create → Pages → Upload assets**
2. همین پوشه‌ی `sepahar/` را بکش و رها کن
3. لینک: `https://<PROJECT>.pages.dev`

در هر دو حالت، **کلیدِ هر کاربر در مرورگر خودش** می‌ماند؛ چیزی از حسابت لو نمی‌رود.

## 🔐 امنیت

- کلید فقط در `localStorage` مرورگرِ شماست؛ با دکمه‌ی **حذف کلید و خروج** (تنظیمات) پاک می‌شود.
- کلید جادویی فقط سه دسترسی می‌گیرد: `Zone Read`، `Analytics Read`، `Firewall Read+Edit` — هیچ دسترسی ویرایش DNS یا تنظیمات حساسی ندارد.
- از طریق **API Tokens → Revoke** کلودفلر می‌توانی کلید را هر لحظه بی‌اثر کنی.
- تمام مقادیر API قبل از نمایش، پاک‌سازی می‌شوند (جلوگیری از XSS).

## 🔑 دسترسی‌های موردنیاز کلید

| دسترسی | نوع | دلیل |
|---|---|---|
| Zone | Read | شناسایی و فهرست دامنه‌ها |
| Analytics | Read | ترافیک، کشورها، آی‌پی‌ها |
| Firewall | Read + Edit | رویدادهای حملات + مسدودسازی یک‌کلیکه + حالت زیر آتش |

## 🛠️ نکات فنی

- **بدون وابستگی**: بدون React، بدون Tailwind CDN، بدون کتابخانه‌ی نمودار — نمودارها SVG دست‌ساز است.
- **مصرف API بهینه**: ۶ درخواست موازی در هر سیکل به‌روزرسانی + کش داخلی + توقف خودکار هنگام پنهان بودن تب.
- **APIهای استفاده‌شده**: `zones`، `analytics/zone`، `security/overview`، `security/events`، `firewall/locks/ips`، `security/settings/under-attack-mode`.
- **حفظ داده**: فقط تنظیمات (کلید، دامنه فعال، فاصله‌ی به‌روزرسانی) در `localStorage` با کلید `sepahar.v1`.
