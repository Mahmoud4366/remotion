کلید سپهر را بگیر

یک «کلید API» از کلودفلر می‌سازیم تا سپهر بتواند ترافیک، بازدیدکننده‌ها و حملاتِ دامنه‌های تو را بخواند.
کلیدِ «جادویی» ما، همه‌ی دسترسی‌های لازم را از قبل برای تو تنظیم می‌کند — فقط باید تأیید بزنی.

🪄 کلید جادویی — با یک کلیک صفحه‌ی ساخت کلید کلودفلر را با دسترسی‌های دقیق و از‌پیش‌تنشده باز می‌کند؛ تو فقط دکمه‌ی آبی Create Token را می‌زنی. ساخت کلید 🪄
۱ وارد حساب کلودفلر شو

اگر دکمه‌ی بالا را زدی ولی صفحه‌ی Login آمد، یک‌بار وارد حساب‌ات شو (ایمیلی که دامنه‌هایت را با آن ثبت کرده‌ای) و دوباره دکمه‌ی جادویی را بزن.

 ✓
۲ دکمه‌ی آبی Create Token را بزن

در صفحه‌ای که باز شد، دسترسی‌ها از قبل مشخص‌اند: Zone: Read · Analytics: Read · Firewall: Edit — دامنه‌ها: Include all zones. فقط پایین برو و روی Create Token بزن.

 ✓
۳ کلید را کپی کن (فقط یک‌بار نمایش داده می‌شود!)

یک رشته‌ی بلند و تصادفی می‌آید؛ همین الان کپی‌اش کن. بعد از بستن این پنجره دیگر نمایش داده نمی‌شود، پس دست‌به‌دستش نده و جایی امن ذخیره‌اش کن.

 ✓
۴ بیا عقب — کلید را به پنل بده

به پنل اصلی برو، کلید را در کادر «گام ۲» بچسبان و بزن ورود به پنل. تمام! داشبورد ترافیک، بازدیدکننده‌ها و حملاتت جلوت باز می‌شود.

 ✓

🔐 کلیدت چه دسترسی‌هایی دارد؟ (و چرا؟)

🌐 خواندن دامنه‌ها (Zone · Read)تا دامنه‌های حساب‌ات را پیدا کند و فهرست آن‌ها را در پنل نشان دهد.
📊 خواندن تحلیل‌ها (Analytics · Read)مهم‌ترین‌ها از همه: چند گیگ ترافیک، چند نفر وارد شدند، از کدام کشورها و کدام آی‌پی‌ها.
🛡️ خواندن و ویرایش فایروال (Firewall · Read + Edit)رویدادهای حملات را ببینی و با یک کلیک آی‌پی حمله‌گر را مسدود کنی؛ حتی حالت «زیر آتش».

🔒 امنیتِ کلیدت — مهم بخوان

✓ کلید فقط در مرورگر خودت (حافظه‌ی محلی) ذخیره می‌شود؛ هیچ سروری، هیچ دیتابیس و هیچ نفر سوم آن را نمی‌بیند.
✓ سپهر یک فایل مستقل است بدون بک‌اند؛ فقط از مرورگر تو به api.cloudflare.com زده می‌شود.
✓ هر وقت خواستی، از همان صفحه‌ی API Tokens کلودفلر کلید را Revoke کن و کل دسترسی‌ها می‌پرد.
✓ این کلید هیچ دسترسی «ویرایش DNS» یا «ویرایش تنظیمات حساس» ندارد — حتی اگر کسی آن را ببیند، کار خطرناکی از دستش برنمی‌آید.

❓ سؤالات رایج

صفحه‌ی ساخت کلید باز شد ولی دسترسی‌ها خالی است؟
صفحه را یک‌بار بازم کن — گاهی کلودفلر فیلدهای پیش‌تنشده را دیرهنگام می‌کشد. اگر باز هم نبود، دستی انتخاب کن: بخش Zone را بزن، Read را فعال کن، بعد Analytics را Read و Firewall را Edit. دامنه‌ها را Include all zones بگذار.
پنل گفت «کلید نامعتبر»؟
۱) موقع کپی‌کردن، فاصله‌ی قبل و بعد کلید را پاک کن. ۲) مطمئن شو کلیدِ دقیقاً همین ساختار را ساختی (سه دسترسی بالا). ۳) اگر کلیدت از قبل ساخته شده با دسترسی‌های دیگری، بسازش کن و با همین کلید جادویی یکی جدید بساز.
«Account ID» چیست و کِی باید واردش کنم؟
سپهر معمولاً خودش همه‌چیز را پیدا می‌کند. فقط اگر پنل از تو Account ID خواست: در داشبورد کلودفلر، آدرس بالای مرورگرت را نگاه کن — dash.cloudflare.com/اینجای ۳۲ کاراکتری/... — همان را کپی کن و در کادر پنل بچسبان.
آیا باید برای هر مرورگر/گوشی یک کلید بسازم؟
نه. همان یک کلید را در هر جایی که می‌خواهی استفاده کن (گوشی، لپ‌تاپ، مرورگر دیگر) — همان‌طور که رمز یک حساب، همه‌جا یکی است. اگر خواستی، می‌توانی برای هر دستگاه کلید جدا هم بسازی.
چطور کلید را برای همیشه بی‌اثر کنم؟
به dash.cloudflare.com/profile/api-tokens برو، در لیست کلیدها آن را پیدا کن، روی ⋯ بزن و Revoke Token. فوری، همه‌ی دسترسی‌های آن می‌پرد.
اگر از اکانت فرعی/مشترک استفاده می‌کنم چه؟
مهم نیست اکانتت چه نوعی باشد؛ به شرط آنکه برای دامنه‌هایت دسترسی داشته باشی. کلید جادویی روی همه‌ی حساب‌ها و دامنه‌های حسابت تنظیم می‌شود و سپهر در همین حساب می‌چرخد.
